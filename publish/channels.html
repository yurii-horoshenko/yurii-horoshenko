Instagram

Аккаунт у вас профессиональный (креатор) и подключён к приложению, поэтому публикация и чтение по API доступны (✅). Био, ссылка и фото профиля по API по-прежнему не меняются (❌). Строки про био и фото относятся к любому типу аккаунта.

ФункцияAPIБраузерПояснение
Публиковать посты✅⚠️API: только профессиональный аккаунт (бизнес, креатор); у вас креатор. Права в приложении добавлены, аккаунт подключён, токен сохранён, право на публикацию проверено запросом лимита (публикацию не пробовал). Только картинка или видео, текстовых постов нет; картинка JPEG по публичной ссылке.
Менять био и ссылку❌⚠️Био и сайт API только читает, записи в документации не нашёл.
Менять фото профиля❌⚠️Эндпоинта для этого не нашёл.
Писать в личные сообщения❓❓Для профессионального аккаунта в API есть право instagram_business_manage_messages (оно было в запросе согласия), но в приложение я его не добавлял и не проверял. Через браузер не проверял.
Читать свой профиль✅⚠️API: только профессиональный аккаунт, право instagram_business_basic. Проверено 2026-10-21: запрос профиля вернул HTTP 200.
  • Токен Instagram живёт 60 дней (до ~2026-12-20); по документации Meta его можно продлевать запросом обновления, я этого не проверял.

TikTok

По документации TikTok Content Posting API. Пока ничего не настроено и не проверено.

ФункцияAPIБраузерПояснение
Публиковать видео и фото⚠️❓Direct Post, право video.publish. До аудита приложения всё публикуется только приватно (SELF_ONLY), аккаунт на момент публикации должен быть закрытым; у неаудированного приложения до 5 пользователей в сутки. Фото принимаются только по ссылке с подтверждённого домена.
Публиковать текстовые посты❌❌В TikTok нет текстовых постов.
Менять био, ссылку, фото профиля❌❓Методов для этого в документации публикации не нашёл.
Писать в личные сообщения❌❓В Content Posting API нет. Через браузер не проверял.
  • Для публичных постов нужен аудит приложения у TikTok (форма с описанием использования); сроки и результат не гарантированы.
  • Для резюме и поиска работы канал малополезен: нужны видео.
